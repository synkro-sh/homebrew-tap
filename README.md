# Synkro Homebrew tap

Homebrew distribution for the [Synkro](https://github.com/synkro-sh/synkro-rs) CLI.

This repository holds two things: the formula Homebrew reads, and the compiled
binaries it downloads. Releases are published here by the `release` workflow in
`synkro-sh/synkro-rs`; nothing in this repo is edited by hand.

## Install

This repository is **private**, so Homebrew needs a GitHub token to read both
the tap and the release assets. Create one with `repo` scope at
<https://github.com/settings/tokens>, then:

```bash
export HOMEBREW_GITHUB_API_TOKEN=ghp_your_token_here

brew tap synkro-sh/tap
brew install synkro
```

Add the `export` line to your shell profile — `brew upgrade` needs the token
too, and without it the upgrade fails at the download step.

Verify:

```bash
synkro --version
```

### Why the token is required

Homebrew sends no credentials when fetching a formula's `url`, so a private
release asset would answer `404`. The formula therefore uses a custom download
strategy (`lib/private_strategy.rb`) that resolves the asset through the GitHub
REST API and attaches your token. If the token is missing or lacks access, the
install stops with a message naming the cause rather than an opaque 404.

If this tap is ever made public, delete `lib/private_strategy.rb`, drop the
`using:` clause from each `url` in the formula, and the token requirement
disappears.

## Supported platforms

| Platform | Target triple |
|---|---|
| macOS (Apple Silicon) | `aarch64-apple-darwin` |
| macOS (Intel) | `x86_64-apple-darwin` |
| Linux (x86_64) | `x86_64-unknown-linux-gnu` |
| Linux (arm64) | `aarch64-unknown-linux-gnu` |

Each is built natively on a matching GitHub Actions runner — no
cross-compilation — so the bundled SQLite and rustls dependencies link the same
way they do in a local `cargo build`.

Linux binaries are built on Ubuntu 22.04 and link glibc 2.35, which matches
Homebrew on Linux's supported baseline. They will not run on older glibc.

## Cutting a release

From `synkro-sh/synkro-rs`:

```bash
git tag v0.2.0
git push origin v0.2.0
```

The workflow builds all four targets, publishes a release here with the
tarballs plus their checksums, and rewrites `Formula/synkro.rb` to point at the
new tag. The formula's version tracks the tag, not the crate version in
`Cargo.toml`.

## Layout

```
Formula/synkro.rb        generated by CI on each release — do not hand-edit
lib/private_strategy.rb  authenticated download strategy for private assets
```
