# Synkro Homebrew tap

Homebrew distribution for the [Synkro](https://github.com/synkro-sh/synkro-rs) CLI.

This repository holds two things: the formula Homebrew reads, and the compiled
binaries it downloads. Releases are published here by the `release` workflow in
`synkro-sh/synkro-rs`; nothing in this repo is edited by hand.

## Install

```bash
brew tap synkro-sh/tap
brew install synkro
```

Verify:

```bash
synkro --version
```

No token or GitHub login is needed. This tap is public even though the CLI
source repository is private — only the built binaries are published here.

## Supported platforms

| Platform | Target triple |
|---|---|
| macOS (Apple Silicon) | `aarch64-apple-darwin` |
| macOS (Intel) | `x86_64-apple-darwin` |
| Linux (x86_64) | `x86_64-unknown-linux-gnu` |
| Linux (arm64) | `aarch64-unknown-linux-gnu` |

macOS and Linux x86_64 are built natively on matching runners. Linux arm64 is
cross-compiled under `cross`, because GitHub's free arm64 Linux runners are
available to public repositories only and `synkro-rs` is private.

Linux binaries are built on Ubuntu 22.04 and link glibc 2.35, matching Homebrew
on Linux's supported baseline. They will not run on older glibc.

## Cutting a release

From `synkro-sh/synkro-rs`:

```bash
git tag v0.2.0
git push origin v0.2.0
```

The workflow builds each target, publishes a release here with the tarballs,
and rewrites `Formula/synkro.rb` to point at the new tag. The formula's version
tracks the tag, not the crate version in `Cargo.toml`.

## Layout

```
Formula/synkro.rb   generated by CI on each release — do not hand-edit
```
